Run the tests with:

    ./tests/local/run.sh

Everything needed (WordPress test suite, PHPUnit, polyfills, test database) is
set up on the first run. See tests/local/README.md for details and settings.

The older, manual route - checking the plugin out inside a wordpress-develop
tree and running phpunit.phar in this folder against tests/bootstrap.php - still
works and is described at:
https://make.wordpress.org/core/handbook/testing/automated-testing/phpunit/

Tipp: Use print "hello world" for dumping variables and output to CLI
